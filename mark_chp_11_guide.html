一、先掌握第 11 章的「大地图」

第 11 章非常适合出 Bible Quiz 的「先后顺序、地点、人物、原话、数字与重复事件」题。尤其要把无花果树与圣殿洁净放在一起记，因为马可刻意把两个事件夹在中间。

11:12-14耶稣咒诅无花果树⭐⭐⭐⭐⭐
11:15-19洁净圣殿⭐⭐⭐⭐⭐

考试时最重要的主线：
进耶路撒冷 → 骑驴 → 众人喊「和散那」 → 无花果树 → 洁净圣殿 → 无花果树枯干 → 信心/祷告 → 权柄争辩
🔥 本章有一个非常值得记的「夹心结构」：
无花果树（11:12-14） → 圣殿（11:15-19） → 无花果树（11:20-21）
看到「无花果树」时，不要只记成一个独立神迹；它和圣殿事件在叙事上紧密相连。
二、11:1-11 荣耀进入耶路撒冷——人物、地点、动作都要背
① 耶稣到了哪里附近？
耶稣将近耶路撒冷，到了伯法其和伯大尼，在橄榄山那里。
🔥 地点链：伯法其 → 伯大尼 → 橄榄山 → 耶路撒冷。
② 耶稣差谁去牵驴？
差两个门徒去。（⚠️ 马可没有在这里说出这两个门徒的名字。不要自行补成彼得、约翰等）。
③ 驴在哪里？该怎么说？
在村子里，一匹驴驹拴在门外街上。耶稣吩咐：「把它解开牵来。」若有人问为什么做，就回答：「主要用它。」
🔥 超高频细节：驴驹 → 拴在门外 → 解开 → 牵来 → 主需要它。
④ 门徒把什么搭在驴上？众人做什么？
门徒把自己的衣服搭在驴上，耶稣就骑上。有许多人把衣服铺在路上；还有人把田间的树枝砍下来铺在路上。
⚠️ 两种东西：衣服 ＋ 树枝。不要只记成棕榈枝；马可 11 章明确写的是「田间的树枝」。
⑤ 众人喊什么？（必背原话）
「和散那！奉主名来的是应当称颂的！」
「那将要来的我祖大卫之国是应当称颂的！高高在上和散那！」
🔥 注意：马可 11 章有「我祖大卫之国」这个独特表达，Quiz 若问原话，要按马可记载回答。
⑥ 耶稣进了哪里？为什么出城？
耶稣进了耶路撒冷，入了圣殿；周围看了各样物件。因为时候已经晚了，就和十二个门徒出城往伯大尼去。
🔥 时间细节：「时候已经晚了」→ 出城 → 往伯大尼。
三、11:12-14 无花果树——极容易考「时间＋外观＋结果」
① 第二天发生什么？为什么找果子却找不着？
他们从伯大尼出来，耶稣饿了。远远看见一棵无花果树，树上有叶子，就往那里去。到了树下竟找不着什么，不过有叶子；因为不是收无花果的时候。
② 耶稣说了什么？
「从今以后，永没有人吃你的果子。」门徒也听见了。
🔥 Quiz 重点顺序：从伯大尼出来 → 耶稣饿了 → 远远看见有叶子的无花果树 → 走近寻找 → 没有果子 → 不是收无花果的时候 → 耶稣说永没有人吃你的果子。
⚠️ 很容易漏掉：「耶稣饿了」和「树上有叶子」。这两个细节很适合填空题。
四、11:15-19 洁净圣殿——本章最高频事件之一
① 耶稣到了哪里？赶出哪些人？推倒了什么？
进入耶路撒冷的圣殿。赶出在殿里做买卖的人，推倒兑换银钱之人的桌子和卖鸽子之人的凳子，不许人拿着器具从殿里经过。
② 耶稣教训了什么？（核心必背）
「经上不是记着说：我的殿必称为万国祷告的殿吗？你们倒使它成为贼窝了。」
🔥 两个对比：神的心意：万国祷告的殿 ｜ 人的败坏：贼窝。
③ 谁听见并想除灭耶稣？晚上发生什么？
祭司长和文士听见了，就想法子要除灭耶稣，又怕祂，因为众人都希奇祂的教训。到了晚上，耶稣和门徒又出城去。
五、11:20-26 无花果树枯干——信心与饶恕
① 什么时候看见？枯干到什么程度？谁首先想起来？
早晨，他们从那里经过，看见无花果树连根都枯干了（⚠️ 「连根都枯干」是核心细节）。彼得想起耶稣所说的话，就对祂说：「拉比，请看！你所咒诅的无花果树已经枯干了。」
② 耶稣借此教导什么？祷告与饶恕的命令是什么？
• 「你们当信服神。」若有人对这座山说「你挪开此地投在海里」，只要心里不疑惑，只信他所说的必成，就必给他成了。
• 🔥 祷告黄金金句（11:24）：
「所以我告诉你们，凡你们祷告祈求的，无论是什么，只要信是得着的，就必得着。」
• 🔥 饶恕命令（11:25）：
「你们站着祷告的时候，若想起有人得罪你们，就当饶恕他，好叫你们在天上的父也饶恕你们的过犯。」
六、11:27-33 权柄问题——超级适合 Quiz 对话题
① 谁来问耶稣？问什么？
祭司长、文士和长老进前来（🔥 三组身份一起记）。问：「你仗着什么权柄做这些事？给你这权柄的是谁呢？」
② 耶稣如何反问？对方为什么不敢回答？
耶稣反问：「约翰的洗礼是从天上来的？是从人间来的？你们可以回答我。」
他们彼此商议：若说从天上来，祂必问为什么不信他；若说从人间来，却又怕百姓，因为众人真以为约翰是先知。
③ 双方最终的答辩结果：
他们回答说：「我们不知道。」
耶稣说：「我也不告诉你们，我仗着什么权柄做这些事。」
七、第 11 章最容易混淆的「人物」
人物身份 / 动作
两个门徒奉耶稣差遣去牵驴驹；马可未点名（不是十二人全去）
十二个门徒耶稣进圣殿后与祂一同出城往伯大尼
彼得第二天早晨看见无花果树枯干时，首先发声报告
祭司长、文士、长老在圣殿里质问耶稣行事的权柄
买卖的人 / 兑换银钱者 / 卖鸽子者在圣殿中被耶稣赶出、推倒桌子与凳子
约翰本章提到的是他的洗礼来源；不是他本人到场
八、第 11 章「地点」与「时间」考点
🗺️ 地点移动线：伯法其 → 伯大尼 → 橄榄山 → 耶路撒冷圣殿（观看） → 出城往伯大尼 → 第二天出来（无花果树） → 圣殿（洁净） → 晚上出城 → 早晨经过（树枯干） → 圣殿（争辩权柄）
重点：伯大尼是极为关键的宿夜来回点，并非所有事件都在耶路撒冷城内。
时间节点发生事件
第一天下午骑驴进京，众人铺衣树枝喊和散那；入圣殿观看各物，因时候已晚出城往伯大尼
第二天早晨从伯大尼出来，耶稣饿了，咒诅只有叶子的无花果树；进圣殿洁净赶出买卖人
第二天晚上出城去
第三天早晨经过看见无花果树连根都枯干；彼得指出；耶稣教导信心、祷告与饶恕；圣殿辩权柄
九、第 11 章最容易掉进去的「混淆陷阱」
⚠️ 两个门徒 vs 十二门徒：两个门徒去牵驴；十二门徒随主出城。
⚠️ 第一次进圣殿 vs 洁净圣殿：11:11 只是观看物件；11:15 第二天才正式推倒桌子赶出买卖人。
⚠️ 树叶 vs 树枯干：第一天有叶无果；第二天早晨连根枯干。
⚠️ 谁报告树枯干？：明确是彼得。
⚠️ 树枝种类：马可 11:8 明确写的是「田间的树枝」，不要直接写成棕榈枝。
⚠️ 驴的称呼：马可明确记载是「驴驹」，且拴在门外街上。
十、第 11 章核心「动作顺序题」训练
1. 牵驴入城：两门徒 → 门外街上解开驴驹 → 主要用它 → 搭衣服骑上 → 铺衣服树枝 → 和散那 → 进圣殿观看 → 天晚往伯大尼
2. 无花果树与洁净圣殿：伯大尼出来 → 耶稣饿了 → 看见叶树无果 → 宣告永无人吃 → 进圣殿赶买卖推倒桌凳 → 万国祷告的殿变贼窝
3. 树枯干与教导：早晨经过 → 连根枯干 → 彼得想起报告 → 信服神 → 祷告信是得着 → 站着祷告当饶恕
4. 权柄交锋：祭司长文士长老问权柄 → 耶稣反问约翰洗礼 → 对方怕百姓说不知道 → 耶稣不告诉
