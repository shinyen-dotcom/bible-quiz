🔥 考试时最重要的主线：
约翰预备道路 → 耶稣受洗 → 受试探 → 开始传道 → 呼召门徒 → 赶鬼 → 医病 → 祷告 → 医治麻风病人。
把这条线背熟，第一章至少先拿到基本盘。
二、1:1-8 施洗约翰——超高频考点
① 马可福音怎么开头？

「神的儿子，耶稣基督福音的起头。」

⚠️ 重点对比
马可没有像马太一样从耶稣家谱开始；也没有像路加一样从出生故事开始。而是直接进入：施洗约翰 → 耶稣。
② 施洗约翰是谁？

他是：「在旷野有人声喊着说：预备主的道，修直他的路。」

③ 约翰在哪里传道？

📍 旷野，并且宣讲悔改的洗礼，使罪得赦。所以三个关键词一起记：旷野 → 悔改 → 洗礼。

④ 约翰穿什么？吃什么？

这是 Bible Quiz 非常喜欢考的细节：

  • 衣服：骆驼毛的衣服
  • 腰间：皮带
  • 食物：蝗虫、野蜜
🔥 建议直接背：骆驼毛 + 皮带 + 蝗虫 + 野蜜（不要把“野蜜”记成蜂蜜，“蝗虫”记成别的昆虫）。
⑤ 约翰的信息是什么？

「有一位在我以后来的，能力比我更大，我就是弯腰给他解鞋带也是不配的。」

而且约翰是用水施洗，耶稣将用圣灵施洗。

约翰耶稣
水圣灵
预备道路真正的主
能力较小能力更大
三、1:9-11 耶稣受洗——必须背

这是第一章最值得背诵的事件之一。耶稣：📍 从拿撒勒来 📍 在约旦河 📍 受约翰施洗。

然后发生：天裂开了，圣灵仿佛鸽子降在祂身上。从天上有声音：「你是我的爱子，我喜悦你。」

Quiz 易混淆 顺序：天裂开 → 圣灵仿佛鸽子降下 → 天上的声音。
四、1:12-13 耶稣受试探

圣灵「随即」把耶稣催到旷野（马可非常喜欢“随即”这个词）。

核心要素：40天 → 撒但 → 野兽 → 天使。

⚠️ 不要把马太、路加福音详细的三次试探内容硬套进马可。马可这里没有详细写三次试探内容。
五、1:14-20 耶稣开始传道 + 呼召门徒 ⭐⭐⭐⭐⭐

约翰被下在监里之后，耶稣来到加利利宣讲神的福音：

🔥 马可福音 1:15「日期满了，神的国近了。你们当悔改，信福音。」
六、第一次呼召门徒——西门和安得烈

地点：📍 加利利海边；他们在做什么：撒网（因为他们是打鱼的）。

耶稣说：「来跟从我，我要叫你们得人如得鱼一样。」

七、第二组：雅各和约翰
第一组 vs 第二组对比
• 第一组（西门 + 安得烈）：正在撒网。
• 第二组（雅各 + 约翰）：正在船上与父亲西庇太及雇工一起补网。

🔥 四个最先被呼召的人顺序：西门 → 安得烈 → 雅各 → 约翰。

八、1:21-28 迦百农赶鬼

地点：📍 迦百农。耶稣在安息日进入会堂教训人，众人希奇因为祂教训他们正像有权柄的人。

污鬼喊：「拿撒勒人耶稣...我知道你是谁，乃是神的圣者。」（⚠️ 谁称耶稣为“神的圣者”？👉 污鬼，不是门徒）。

耶稣责备：「不要作声，从这人身上出来吧！」污鬼叫那人抽疯喊叫就出来了。众人都惊讶：这是一个有权柄的新道理！

九、1:29-34 医治彼得岳母

进入西门和安得烈的家，西门的岳母患热病。耶稣拉着她的手扶她起来，热就退了。

🔥 Quiz 非常喜欢问：耶稣医治彼得岳母之后，她做了什么？👉 答案：服事他们。

十、日落以后发生什么？

时间点：天晚日落的时候，众人把一切害病的、被鬼附的都带到耶稣那里，合城的人聚集门前。

⚠️ 特别细节：耶稣治好许多人，赶出许多鬼，不许鬼说话，因为鬼认识祂。

十一、1:35——第一章非常重要的属灵动作
🔥🔥🔥「次日早晨，天未亮的时候，耶稣起来，到旷野地方去，在那里祷告。」

四个连贯动作：早晨 → 天未亮 → 旷野 → 祷告。

十二 & 十三、寻找耶稣与离城传道

西门和同伴去找耶稣说「众人都找你」。耶稣回答：「我们可以往别处去，到邻近的乡村，我也好在那里传道，因为我是为这事出来的。」

十四 - 十七、医治长大麻风的人全过程

1. 态度：跪下求「你若肯，必能叫我洁净了。」（相信能力，求的是心愿）。

2. 耶稣反应：动了慈心 → 伸手摸他 → 「我肯，你洁净了吧！」

3. 两个命令：① 严严嘱咐什么都不可告诉人；② 把身体给祭司察看，献摩西吩咐的礼物。

4. 结果与因果：那人出去广传这件事 → 导致耶稣不得再明明进城，只能在外边旷野地方。
