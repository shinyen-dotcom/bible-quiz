一、先掌握第 10 章的「大地图」

马可福音第 10 章可以分成 6 个主要事件。第 10 章非常适合出「人物＋问题＋原话＋顺序」的题目，所以不要只背故事，要把每一段的关键动作一起记住。

段落内容Quiz 重要度
10:1-12婚姻、休妻与神所配合的⭐⭐⭐⭐⭐
10:13-16耶稣为小孩子祝福⭐⭐⭐⭐⭐
10:17-31有钱人求永生、跟从耶稣⭐⭐⭐⭐⭐
10:32-34第三次预言受难、受死、复活⭐⭐⭐⭐⭐
10:35-45雅各约翰求荣耀、谁为大⭐⭐⭐⭐⭐
10:46-52耶利哥路旁巴底买呼求、得看见⭐⭐⭐⭐⭐
考试时最重要的主线：
婚姻 → 小孩子 → 有钱人 → 受难预言 → 雅各约翰求位 → 谁为大 → 巴底买得医治

🔥 第 10 章其实一直在问一个核心问题：什么叫真正跟从耶稣？
婚姻上忠于神的心意 → 像小孩子接受神的国 → 放下财富依靠神 → 接受十字架道路 → 不争地位而服事 → 像巴底买一样呼求并跟随耶稣。

二、10:1-12 婚姻、休妻——非常容易出细节题
① 耶稣到了哪里？
📍 犹太境内、约旦河外。众人又聚集到祂那里，祂又照常教训他们。
② 谁来试探耶稣？问了什么？
法利赛人。他们问：「人休妻可以不可以？」
⚠️ Quiz 陷阱 不要把问题记成「男人可不可以休妻？」——Quiz 很可能要求你说出他们实际问的原话问题。
③ 耶稣反问他们什么？
「摩西吩咐你们的是什么？」他们回答：摩西准许写了休书便可以休妻。
④ 耶稣为什么说摩西这样写？
因为他们的心硬。🔥 关键词：休书 → 摩西 → 心硬。
⑤ 耶稣把重点带回创造：
「但从起初创造的时候，神造人是造男造女。」因此人要离开父母，与妻子连合，二人成为一体。
🔥 最重要结论：
「神所配合的，人不可分开。」（10:9）
⑥ 进屋以后，门徒又问这件事：
耶稣告诉他们：人若休妻另娶，就是犯奸淫；妻子若离弃丈夫另嫁，也是犯奸淫。
⚠️ Quiz 很容易把「众人面前的讨论」和「进屋以后门徒再问」混在一起。要记住：
法利赛人问 → 耶稣回答 → 进屋 → 门徒再问 → 耶稣进一步说明。
三、10:13-16 小孩子——第 10 章必背
① 谁把小孩子带到耶稣那里？门徒做了什么？
有人把小孩子带到耶稣那里，要祂摸他们。门徒责备那些人。
耶稣看见就恼怒，对门徒说：「让小孩子到我这里来，不要禁止他们，因为在神国的，正是这样的人。」
② 非常重要的动作顺序：
🔥 建议直接背：让小孩子来 → 不要禁止 → 抱着 → 按手 → 祝福。
③ 必背 10:15 原文：
🔥🔥🔥 「我实在告诉你们，凡要承受神国的，若不像小孩子，断不能进去。」
⚠️ 注意经文是「承受神国」＋「不像小孩子」＋「断不能进去」。不要把它改记成「像小孩子一样单纯」等概括说法；Bible Quiz 很可能考原句。
四、10:17-31 有钱人——不要把别的福音书细节混进来
① 这个人怎么来到耶稣面前？
跑来，跪在耶稣面前，问祂：「良善的夫子，我当做什么事才可以承受永生？」
🔥 三个动作：跑来 → 跪下 → 发问。
② 耶稣先问他什么？诫命提到哪些？
「你为什么称我是良善的？除了神一位之外，再没有良善的。」然后耶稣提到诫命：不可杀人、不可奸淫、不可偷盗、不可作假见证、不可亏负人、当孝敬父母。
③ 这个人回答什么？
「夫子，这一切我从小都遵守了。」（⚠️ 「从小」非常容易成为填空题）。
④ 耶稣看着他，然后发生什么？
「耶稣看着他，就爱他。」然后说：
「你还缺少一件：去变卖你所有的，分给穷人，就必有财宝在天上；你还要来跟从我。」（🔥 这是本段最重要的命令）。
⑤ 他的反应是什么？
听见这话，脸上就变了色，忧忧愁愁地走了，因为他的产业很多。
🔥 顺序一定记：耶稣爱他 → 吩咐变卖分给穷人 → 来跟从 → 他脸变色 → 忧忧愁愁 → 因产业很多而走了。
⑥ 骆驼穿过针的眼：
耶稣说：「有钱财的人进神的国是何等的难哪！」门徒希奇祂的话。耶稣又说：「小子，倚靠钱财的人进神的国是何等的难哪！骆驼穿过针的眼，比财主进神的国还容易呢。」
门徒问：「这样谁能得救呢？」耶稣回答：「在人是不能，在神却不然，因为神凡事都能。」
⑦ 彼得的问题与耶稣的应许：
彼得说：「看哪，我们已经撇下所有的跟从你了。」
耶稣回答：为祂和福音撇下房屋、弟兄、姐妹、父母、儿女、田地的，今世得百倍，并且要受逼迫；来世必得永生。
🔥 最后出现：「然而，有许多在前的将要在后，在后的将要在前。」
五、10:32-34 第三次预言受难——顺序题超高频
• 往哪里去？ 上耶路撒冷去。
• 耶稣走在前头，门徒惊奇，跟从的人也害怕。耶稣把十二个门徒带到一边，把自己将要遭遇的事告诉他们。
预言重点内容对比
第 1 次（8:31）受许多苦 → 被弃绝 → 被杀 → 三天后复活
第 2 次（9:31）被交在人手里 → 被杀 → 三天后复活
第 3 次（10:33-34）交给祭司长和文士 → 定死罪 → 交给外邦人 → 戏弄、吐唾沫、鞭打、杀害 → 三天后复活
🔥 第 10 章的第三次预言最详细。尤其背熟这个顺序：
祭司长文士 → 定死罪 → 交给外邦人 → 戏弄 → 吐唾沫 → 鞭打 → 杀害 → 三天后复活。
六、10:35-45 雅各和约翰求位——极容易和彼得混淆
① 谁来求？求什么？
西庇太的儿子雅各、约翰。他们说：「夫子，我们无论求你什么，愿你给我们做。」（⚠️ 这里不是彼得，也不是全部十二门徒）。
耶稣问：「要我给你们做什么？」他们求：在耶稣的荣耀里，一个坐在右边，一个坐在左边。
② 耶稣如何回答？
「你们不知道所求的是什么。」然后问他们能不能喝祂所喝的杯、受祂所受的洗。他们回答：「我们能。」耶稣说他们要喝祂所喝的杯，也要受祂所受的洗；但坐在左右不是祂可以赐的，乃是为谁预备的，就赐给谁。
③ 其他十个门徒听见以后怎样？
听见雅各、约翰的请求，其他十个门徒就恼怒他们。（⚠️ 这是一道非常典型的人物关系题：雅各约翰求位 → 其他十个门徒恼怒）。
七、10:42-45 「谁为大」——第 10 章核心经文
耶稣叫他们来，说：外邦人有尊为君王的治理他们，有大臣操权管束他们。只是在你们中间不是这样：
• 「你们中间谁愿为大，就必作你们的用人；」
• 「在你们中间谁愿为首，就必作众人的仆人。」
🔥 记忆对比：外邦人的模式：为大 → 管束别人；耶稣的模式：为大 → 作众人的用人 / 仆人。
🔥🔥🔥 10:45——整章的神学高峰（全组必背）：
「因为人子来，并不是要受人的服事，乃是要服事人，并且要舍命作多人的赎价。」
三个动作：不是受服事 → 乃是服事 → 舍命作赎价。
八、10:46-52 巴底买——最后一个超高频事件
① 地点在哪里？谁坐在那里？
📍 耶利哥。耶稣同门徒并许多人出耶利哥的时候。
一个讨饭的瞎子，名叫巴底买，是底买的儿子。（⚠️ 「巴底买」本身就是「底买的儿子」的意思；Quiz 可能分别问名字、身份、父亲）。
② 他听见谁经过？喊叫什么？众人怎么对他？
听见是拿撒勒的耶稣，他就喊着说：「大卫的子孙耶稣啊，可怜我吧！」
许多人责备他，不许他作声。但他越发大声喊着：「大卫的子孙哪，可怜我吧！」（🔥 重点：众人阻止 → 他反而更大声）。
③ 耶稣停下来发生什么？（动作细节！）
耶稣站住，说：「叫他过来。」他们就叫那瞎子，说：「放心，起来！他叫你啦。」
他就丢下衣服，跳起来，走到耶稣那里。（⚠️ 「丢下衣服」是非常容易漏掉的细节）。
④ 耶稣问了什么？结果如何？
耶稣问：「要我为你做什么？」巴底买说：「拉波尼，我要能看见。」
耶稣说：「你去吧！你的信救了你了。」
结果：他立刻看见了，就在路上跟随耶稣。（🔥 最后的三个动作：看见 → 立刻 → 跟随）。

十、第 10 章「数字」与「数量」考点
  • 一个人跑来跪在耶稣面前问永生。
  • 十二个门徒被耶稣另外带到一边，听第三次受难预言。
  • 雅各、约翰两个人求坐左右。
  • 其他十个门徒听见后恼怒。
  • 骆驼与针眼是本章最醒目的比喻性画面。
十一、第 10 章「重复出现」的重点

① 「跟从」——贯穿全章：有钱人被邀请「来跟从我」忧愁离开；巴底买最后「就在路上跟随耶稣」。（一个离开，一个跟随；漂亮的对比）。
② 「要我为你做什么？」：问雅各、约翰（求荣耀、求左右）；问巴底买（我要能看见）。
③ 「谁为大」与「作仆人」：雅各约翰追求位置 → 耶稣教导服事。「为大」不是靠地位，而是靠服事。
④ 「在前的 / 在后的」：10:31「有许多在前的将要在后，在后的将要在前。」翻转人的价值观。

十二、第 10 章最容易出「顺序题」的地方（闭眼复述 6 条）
1. 法利赛人 → 问休妻 → 摩西休书 → 心硬 → 创造 → 神所配合的不可分开
2. 小孩子 → 门徒责备 → 耶稣恼怒 → 让小孩子来 → 抱着 → 按手 → 祝福
3. 有钱人 → 跑来 → 跪下 → 问永生 → 从小遵守 → 耶稣爱他 → 变卖分给穷人 → 忧愁离开
4. 上耶路撒冷 → 第三次预言 → 祭司长文士 → 外邦人 → 戏弄吐唾沫鞭打 → 杀害 → 三天复活
5. 雅各约翰求左右 → 其他十门徒恼怒 → 耶稣讲服事 → 人子服事人 → 舍命作赎价
6. 巴底买呼求 → 众人责备 → 越发大声 → 耶稣叫他 → 丢下衣服 → 跳起来 → 我要能看见 → 立刻看见 → 跟随耶稣
十四、几个超级容易「串台」的陷阱
容易混淆正确记法
法利赛人 vs 门徒法利赛人先问休妻；进屋后门徒再问
小孩子 vs 有钱人小孩子要「接受/承受」神国；有钱人却因产业很多而忧愁离开
雅各约翰 vs 其他十门徒雅各约翰求左右；其他十个听见后恼怒
雅各约翰 vs 巴底买两者都遇到「要我给你做什么」，但一个求地位，一个求看见
三次受难预言第 10 章是第三次，而且是三次中细节最丰富的一次
马可 vs 马太/路加的有钱人本章按马可记「有一个人」，不要擅自加入其他福音书身份标签
巴底买 vs 一般医治故事巴底买不是安静等待；他被阻止后「越发大声」呼求
十六、🗺️ 第 10 章「地点路线」记忆
犹太境内、约旦河外 → 众人聚集、教训人 → 屋里（门徒继续问婚姻） → 有人带小孩子来 → 上路 / 往耶路撒冷（第三次预言受难） → 耶利哥 → 出耶利哥（路旁：巴底买） → 看见，在路上跟随耶稣
