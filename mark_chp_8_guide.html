把这条线背熟，第八章的基本盘就稳了[cite: 41]。
二、8:1-10 四千人吃饱——不要和五千人吃饱混在一起
① 这是几千人？
四千人[cite: 41]。
⚠️ Bible Quiz 最容易把「五千人吃饱」和「四千人吃饱」混在一起[cite: 41]：
• 马可 6 章：五千人 → 五个饼 → 两条鱼 → 十二个篮子[cite: 41]。
• 马可 8 章：四千人 → 七个饼 → 几条小鱼 → 七个筐子[cite: 41]。
② 众人跟随耶稣多久？为什么怜悯他们？
三天[cite: 41]。因为他们同耶稣在这里已经三天，也没有吃的[cite: 41]。耶稣特别担心他们「从远处来」，若叫他们饿着回去，就会在路上困乏[cite: 41]。
③ 门徒手里有什么？饭后剩下多少？
七个饼，还有几条小鱼[cite: 41]。饭后剩下七筐子[cite: 41]。
🔥 这一组直接背：四千人 → 三天 → 七个饼 → 几条小鱼 → 七筐子[cite: 41]。
三、四千人 vs 五千人——全章最容易混淆之一
神迹类别具体数字与细节对照
五千人（马可 6 章）[cite: 41] • 五个饼 ＋ 两条鱼
• 十二个篮子
• 发生在加利利海附近的旷野场景[cite: 41]
四千人（马可 8:1-9）[cite: 41] • 七个饼 ＋ 几条小鱼
• 七筐子
• 众人跟随三天，众人没有吃的[cite: 41]
⚠️ 特别注意 「篮子」与「筐子」不要混答[cite: 41]！
• 四千人吃饱后剩下多少筐？→ 七筐子[cite: 41]
• 四千人有几个饼？→ 七个[cite: 41]
• 众人跟随耶稣多久？→ 三天[cite: 41]
• 这次是四千还是五千？→ 四千[cite: 41]
🔥 一个好记法：4 千 → 7 饼 → 7 筐[cite: 41]
四、8:11-13 法利赛人求神迹——一个很短但很容易考的段落
法利赛人出来盘问耶稣，并且向祂求从天上来的神迹，想要试验祂[cite: 41]。
耶稣听见就：「心里深深地叹息」[cite: 41]。然后说：「为什么这世代求神迹呢？我实在告诉你们，没有神迹给这世代看。」[cite: 41]随后耶稣离开他们，又上船往海那边去了[cite: 41]。
⚠️ 易混：他们不是单纯好奇，而是「试验」耶稣[cite: 41]。求的是「从天上来的神迹」[cite: 41]。耶稣的反应是「心里深深地叹息」[cite: 41]。这里不要自行加入马太福音的其他措辞，以马可文本为准[cite: 41]。
🔥 重要动作顺序：法利赛人出来 → 盘问 → 求神迹试验 → 耶稣深深叹息 → 上船离开[cite: 41]。
五、8:14-21 忘记带饼——「酵」是超高频关键词

门徒忘了带饼，在船上除了一个饼以外，没有别的食物[cite: 41]。耶稣吩咐他们：「你们要谨慎，防备法利赛人的酵和希律的酵。」[cite: 41]

① 门徒误会什么？耶稣真正要他们想什么？
门徒彼此议论，是因为自己没有饼[cite: 41]。耶稣真正要他们想的是：有没有明白耶稣刚刚所做的事[cite: 41]！
耶稣提醒他们：五个饼给五千人，收拾的零碎装满十二个篮子；七个饼给四千人，收拾的零碎装满七个筐子[cite: 41]。最后问：「你们还是不明白吗？」[cite: 41]
🔥 Quiz 关键词：一个饼 → 法利赛人的酵 → 希律的酵 → 门徒以为是没有饼 → 耶稣提醒五饼、七饼 → 你们还是不明白吗？[cite: 41]
六、「法利赛人的酵」和「希律的酵」——不要漏掉希律
耶稣不是只说：❌ 防备法利赛人的酵；而是：✅ 防备法利赛人的酵和希律的酵[cite: 41]。
• 「酵」不是指船上真的有一袋酵母[cite: 41]。
• 门徒想到的是「饼」；耶稣谈的是「酵」[cite: 41]。
• 五饼对应五千、十二篮；七饼对应四千、七筐[cite: 41]。
🔥 如果比赛问：「耶稣吩咐门徒防备谁的酵？」👉 答案必须完整：法利赛人和希律[cite: 41]。
七、8:22-26 伯赛大瞎子——医治过程排序题（必背！）

地点：📍 伯赛大。有人带一个瞎子来，求耶稣摸他[cite: 41]。

🔥 医治过程七步完整顺序：
① 耶稣拉着瞎子的手 → 领他到村外[cite: 41]
② 吐唾沫在他眼睛上 → 按手在他身上[cite: 41]
③ 问他：「你看见什么了？」[cite: 41]
④ 他回答：「我看见人了，他们好像树木，并且行走。」[cite: 41]
⑤ 耶稣又按手在他的眼睛上[cite: 41]
⑥ 他定睛一看，就复了原，样样都看得清楚了[cite: 41]
⑦ 耶稣打发他回家，并且说：「连这村子你也不要进去。」[cite: 41]

🔥 一眼口诀：拉手 → 村外 → 吐唾沫 → 按手 → 看见像树木 → 再按手 → 完全看清 → 不要进村[cite: 41]。

八、伯赛大瞎子 vs 其他医治——特别容易混淆
• 这一段是一个瞎子，不是耳聋舌结的人[cite: 41]。
• 地点是伯赛大[cite: 41]。
• 医治不是一次完成，而是两次按手[cite: 41]。
• 第一次按手后，他看见人「好像树木，并且行走」[cite: 41]。
• 第二次按手后，才「样样都看得清楚了」[cite: 41]。
• 最后耶稣吩咐他不要进村[cite: 41]。⚠️ 「第一次看见」和「完全看清」一定要分清[cite: 41]。
九、8:27-30 彼得认耶稣为基督——全章核心转折

地点：📍 凯撒利亚·腓立比的村庄[cite: 41]。

① 耶稣问门徒什么？
「人说我是谁？」门徒回答：施洗约翰；有人说是以利亚；又有人说是先知里的一位[cite: 41]。
② 第二个问题更重要：
耶稣问：「你们说我是谁？」彼得回答：「你是基督。」（🔥 这是第八章必须背的答案）[cite: 41]。
耶稣随后吩咐他们：「不要告诉人。」（注意：这里是对门徒的严嘱）[cite: 41]。
十、人物答案不要混淆
• 「人说我是谁？」的答案：施洗约翰 / 以利亚 / 先知里的一位[cite: 41]
• 「你们说我是谁？」的答案：彼得：「你是基督。」[cite: 41]
⚠️ Quiz 很喜欢把两个问题调换。记法：众人怎么说？→ 约翰、以利亚、先知；你们怎么说？→ 彼得：基督[cite: 41]。
十一、8:31-33 第一次预言受难——必须熟到能填空

从这时起，耶稣才教训门徒：「人子必须受许多的苦，被长老、祭司长和文士弃绝，并且被杀，过三天复活。」[cite: 41]
🔥 顺序一定要记：受许多的苦 → 被弃绝 → 被杀 → 过三天复活[cite: 41]。

谁把耶稣拉到一边责备祂？耶稣如何斥责？
彼得[cite: 41]。耶稣转过来，看着门徒，就责备彼得说：「撒但，退我后边去吧！因为你不体贴神的意思，只体贴人的意思。」[cite: 41]
🔥 特别注意：耶稣不是称彼得本人就是撒但，而是在责备他所说的话和背后的拦阻[cite: 41]。
十二、彼得「认基督」之后，为什么马上又被责备？
彼得说对了身份：「你是基督」[cite: 41]。但当耶稣说明基督必须受苦、被弃绝、被杀、复活时，彼得不能接受[cite: 41]。
所以：认出耶稣是谁 ≠ 已经明白十字架道路[cite: 41]。
Bible Quiz 若问「彼得为什么被耶稣责备？」👉 关键词：不体贴神的意思，只体贴人的意思[cite: 41]。
十三、8:34-38 跟从耶稣——本章最重要的教导

耶稣叫众人和门徒来，对他们说：「若有人要跟从我，就当舍己，背起他的十字架来跟从我。」[cite: 41]
🔥 三个动作必须背：舍己 → 背起十字架 → 跟从我[cite: 41]。

接下来的核心论述：
• 「因为凡要救自己生命的，必丧掉生命；凡为我和福音丧掉生命的，必救了生命。」[cite: 41]
• 「人就是赚得全世界，赔上自己的生命，有什么益处呢？」[cite: 41]
• 「人还能拿什么换生命呢？」[cite: 41]
十四、8:38——容易被漏掉的结尾
耶稣又说：「凡在这淫乱罪恶的世代，把我和我的道当作可耻的，人子在他父的荣耀里，同圣天使降临的时候，也要把那人当作可耻的。」[cite: 41]
⚠️ Quiz 考点：把谁当作可耻？→ 把耶稣和祂的道当作可耻[cite: 41]。何时当作可耻？→ 在祂父的荣耀里，同圣天使降临的时候[cite: 41]。
十五、第八章最容易混淆的「人物 / 地点」
人物第8章重点动作
彼得说「你是基督」；后来把耶稣拉到一边责备祂；被耶稣斥责[cite: 41]
法利赛人求从天上来的神迹，试验耶稣[cite: 41]
希律出现在「希律的酵」[cite: 41]
门徒忘记带饼；误以为耶稣说酵是因为没有饼[cite: 41]

地点定位：
• 伯赛大 → 瞎子得医治[cite: 41]
• 凯撒利亚·腓立比的村庄 → 彼得认耶稣为基督[cite: 41]
• 海上 / 船中 → 门徒讨论没有饼[cite: 41]
⚠️ 特别注意：「伯赛大」不是彼得认信的地点；认信发生在凯撒利亚·腓立比一带[cite: 41]。

十六、第八章「数字」考点
  • 4,000 人 → 7 个饼 → 7 筐子 → 跟随 3 天[cite: 41]
  • 5,000 人 → 5 个饼 → 2 条鱼 → 12 个篮子（耶稣后来回顾的前一件神迹）[cite: 41]
  • ⚠️ 不要把 4,000 的「七筐」和 5,000 的「十二篮」交换[cite: 41]。
  • 瞎子医治：第一次按手 → 看见人像树木 → 第二次按手 → 完全看清[cite: 41]。
  • 受难预言：受苦 → 弃绝 → 被杀 → 过三天复活[cite: 41]。
十七、第八章「排序题」训练
A. 四千人吃饱：感谢、擘开饼 → 门徒分给众人 → 众人吃并且吃饱 → 收拾剩下的零碎 → 有七筐子[cite: 41]
B. 伯赛大瞎子：拉手领出 → 吐唾沫按手 → 看见人像树木 → 再按手 → 完全看清 → 不要进村[cite: 41]
C. 彼得认信之后：彼得认「基督」 → 耶稣教导受难 → 彼得拉到一边责备 → 耶稣责备彼得 → 教导舍己背十字架[cite: 41]

二十二、五轮小组备战操练法
  1. 第一轮：全员背「大地图」：四千 → 求神迹 → 酵 → 伯赛大 → 基督 → 受难 → 十字架[cite: 41]。
  2. 第二轮：数字闪答：4,000？7 饼？7 筐？3 天？5,000？5 饼？12 篮？两次按手？[cite: 41]
  3. 第三轮：人物闪答：谁说「你是基督」？→ 彼得 ｜ 谁求神迹？→ 法利赛人 ｜ 谁的酵也要防备？→ 希律 ｜ 谁被医治？→ 伯赛大瞎子[cite: 41]。
  4. 第四轮：排序题：四千人吃饱、瞎子医治、彼得认信→受难预言→彼得责备→背十字架[cite: 41]。
  5. 第五轮：反向题：「七筐子」→ 什么事件？「好像树木」→ 谁？在哪里？「你是基督」→ 谁说？「撒但，退我后边去吧」→ 谁对谁说？为什么？[cite: 41]
