🔥 考试主线推进：
撒种 → 四种土地 → 灯 → 量器 → 种子生长 → 芥菜种 → 平静风浪。
特色在于多重比喻连续呈现，需熟记：场景、比喻意象、解释及对应收成数字！
第一部分：4:1–20 撒种的比喻（最高频考点）

① 场景设定：地点在海边。众人极多，耶稣上了一只船坐下；众人都在海边的陆地上（不是耶稣在岸上、众人在船里！）。

② 开篇号召：耶稣首先呼召：「你们听啊！」（本章核心字为“听”）。

③ 所撒的种子代表什么？ 耶稣明确解释：所撒的就是「道」（4:14）。

④ 四种土地与结局对照：

土地类别发生事件灵意解释（失落 / 结果原因）
路旁飞鸟来吃尽了撒但立刻来，把撒在他们心里的道夺了去。
土浅石头地日头出来晒焦，因无根枯干听道欢喜领受，但心里没有根；为道遭患难或逼迫，立刻跌倒。
荆棘里荆棘长起把它挤住，不结实被世上的思虑、钱财的迷惑、别样的私欲挤住，不能结实。
好土里长大结实人听道又领受，结实有三十倍、六十倍、一百倍。

⑤ 比喻的目的：「神国的奥秘只叫你们知道；若是对外人讲，凡事就用比喻。」（4:11）

第二部分：4:21–25 灯的比喻与量器原则

① 灯该放何处？ 人拿灯来，岂是要放在斗底下、床底下，不放在灯台上吗？

② 显露的原则：掩藏的事没有不显出来的，隐瞒的事没有不露出来的（4:22）。

③ 量器的法则：「你们用什么量器量给人，也必用什么量器量给你们，并且要多给你们。因为有的还要给他；没有的，连他所有的也要夺去。」（4:24–25）

第三部分：4:26–29 种子自己生长（马可福音独有）

① 生长的奥秘：神的国如同人把种撒在地上，黑夜睡觉，白日起来，这种就发芽渐长，那人却不晓得如何这样（强调撒种者不明白其生长机理）。

② 三个成长阶段：地生出苗来 → 随后长穗 → 再后穗上结成饱满的子粒。

③ 收成动作：谷既熟了，就用镰刀去割，因为收成的时候到了。

第四部分：4:30–34 芥菜种的比喻

① 对比悬殊：种在地里的时候，虽比地上的百种都小；但长起来比各样的菜都大，长出大枝，天上的飞鸟可以宿在它的荫下。

② 教训方式：若不用比喻就不对他们讲；私下没有人的时候，就把一切的道讲给门徒听。

第五部分：4:35–41 平静风浪（极高频细节题）

① 时间与命令：当那天晚上，耶稣对门徒说：「我们渡到那边去。」

② 同行船只细节：门徒离开众人，把耶稣带去，也有别的船和祂同行（不仅有一条船！）。

③ 风浪与耶稣的位置：波浪打入船内甚至要满了水。耶稣在船尾上，枕着枕头睡觉（船尾 + 枕头 + 睡觉）。

④ 门徒的呼叫：「夫子！我们丧命，你不顾吗？」

⑤ 斥责风海的原话：耶稣起来，斥责风，向海说：「住了吧！静了吧！」风就止住，大大地平静了。

⑥ 耶稣的责备与门徒的惊叹：
• 耶稣说：「为什么胆怯？你们还没有信心吗？」
• 门徒彼此说：「这到底是谁，连风和海也听从他了？」

🧠 第四章对比矩阵与数字考点
考点分类核心项目详细说明与易错警示
四种土壤与障碍 路旁 / 石头 / 荆棘 / 好土 路旁(飞鸟/撒但夺道) → 石头(无根/遭患难逼迫跌倒) → 荆棘(思虑钱财私欲挤住) → 好土(结实30/60/100倍)。
灯不放哪里？ 斗底下、床底下 经文明确是斗底或床底，不是桌子底或箱子底。
作物成长三阶 苗 → 穗 → 饱满的子粒 顺序不可颠倒；熟了之后用“镰刀”收割。
核心数字倍数 三十倍、六十倍、一百倍 严格递增次序：30 → 60 → 100。
风浪中的细节 船尾、枕头、睡觉 称呼是“夫子”；命令是“住了吧！静了吧！”；时间是“那天晚上”。
🚨 第四章高频失分陷阱：
1. 撒种的比喻中，种子就是「道」（4:14），不是信徒，也不是行为。
2. 耶稣教训众人时，耶稣在船上坐着，众人在陆地上（4:1）。
3. 石头地枯干的原因是心里没有根；荆棘地不结实的原因是被思虑、钱财迷惑、私欲挤住。
4. 种子自己生长时，撒种的人黑夜睡觉、白日起来，他却不晓得种子如何生长。
5. 芥菜种下地时是比地上的百种都小，长成后天上的飞鸟宿在荫下。
6. 门徒叫醒耶稣的原话是「夫子！我们丧命，你不顾吗？」（不是“主啊救我”）。
7. 耶稣平息风浪的话是「住了吧！静了吧！」。
